# Cloud Computing Mission Reflection

After completing this mission, the cloud platform that impressed me the most was **Amazon Web Services (AWS)**. I was impressed by the large number of services it provides and how it can support different types of businesses, from startups to large global companies. I also learned that AWS can scale resources depending on the needs of an application.

AWS, Azure, and GCP have many similarities. All three provide services for computing, storage, databases, networking, security, and identity management. They also allow businesses to access cloud resources without needing to maintain all of their own physical hardware. Another similarity is that they provide virtual machines, object storage, and managed database services.

I learned that **business requirements have a major influence on cloud platform selection**. There is no single cloud provider that is best for every company. For example, Azure can be a good choice for an organization that already uses Microsoft technologies, while Google Cloud can be a strong choice for companies focused on AI and machine learning. AWS can be useful for organizations that need a wide variety of services and global infrastructure.

Acting as a **Cloud Solutions Consultant** helped me understand that choosing a cloud platform is not simply about picking the most popular provider. I need to look at the client's budget, existing technology, business goals, scalability requirements, and specific workloads before making a recommendation.

Finally, this mission improved my **GitHub Cloud Computing Portfolio** because I was able to add more organized and practical information about cloud platforms. I now have examples of cloud services, comparisons between AWS, Azure, and GCP, and recommendations based on different business scenarios. This makes my portfolio more complete and shows that I understand not only what cloud services are, but also how they can be applied to real business needs.
