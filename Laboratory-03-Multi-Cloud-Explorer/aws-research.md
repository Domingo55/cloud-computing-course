Amazon Web Services (AWS)

Brief Overview:
Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides many cloud services, including computing power, storage, databases, networking, artificial intelligence, and security. Businesses can use these services without having to own and maintain all the physical hardware themselves.

Global Infrastructure:
AWS has a large global infrastructure consisting of 39 geographic Regions and 123 Availability Zones. These regions are distributed across different parts of the world, allowing businesses to deploy applications closer to their users and improve reliability.

Cloud Management Console:
The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

Four (4) Core Services:

Amazon EC2 – provides virtual servers for running applications.
Amazon S3 – provides scalable object storage for files and data.
Amazon RDS – provides managed relational databases.
AWS Lambda – allows applications to run code without managing servers.

Three (3) Advantages:

Scalability – resources can easily be increased or decreased according to demand.
Wide range of services – AWS provides a large selection of cloud services for different business needs.
Global availability – its many regions and Availability Zones support applications used around the world.

Typical Enterprise Use Cases:
AWS is commonly used for e-commerce websites, application hosting, data backup, disaster recovery, big-data processing, artificial intelligence, and global web applications.
