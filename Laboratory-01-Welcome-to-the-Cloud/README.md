# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I practiced working with Linux, creating a user account, navigating the file system, checking system information, and organizing files. I also created a GitHub repository that will be used as my Cloud Computing Portfolio throughout the semester.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Create and organize files and directories using Linux commands.
* Create and maintain a GitHub repository.
* Document technical work using Markdown.

## Activities Performed

During this laboratory activity, I launched an Ubuntu Linux environment using KillerCoda. I created a new Linux user account with a home directory, Bash shell, and sudo access. I then logged into the new account and checked my username, working directory, and hostname.

I also investigated the Linux environment by checking the Linux distribution, kernel version, CPU information, total memory, and available disk space. I created Markdown files and organized my workspace using Linux commands.

Finally, I created a public GitHub repository for my Cloud Computing Portfolio and added the required laboratory files and folders.

## Linux Commands Used

Some of the Linux commands I used were:

* `whoami` – displays the current username.
* `pwd` – displays the current working directory.
* `hostname` – displays the hostname.
* `adduser` – creates a new user.
* `usermod` – modifies a user account and adds sudo access.
* `su` – switches to another user account.
* `cd` – changes the current directory.
* `mkdir` – creates a directory.
* `ls` – lists files and directories.
* `cat` – displays the contents of a file.
* `nano` – creates and edits text files.
* `uname -r` – displays the kernel version.
* `lscpu` – displays CPU information.
* `free -h` – displays memory information.
* `df -h` – displays disk space information.
