  The three cloud applications that I use the most are Messenger, Gcash, 
and TikTok. I use Messenger to chat with people. I use Gcash to send 
money, pay bills, and buy load. I also use TikTok to watch videos for
entertainment in my spare time.

  Based on what I learned, these three applications are examples of Software
as a Service (SaaS) because I can use them through the internet without 
installing or managing the systems behind them. The companies that created
these applications are the ones responsible for maintaining and updating 
them. They are also examples of the Public Cloud deployment model because
they are available for anyone who creates an account and has internet access.
Before, I did not know that these applications belonged to a cloud service
model.

  I also learned about git and GitHub. At first, I did not understand why 
version control was important, but I've bump into it when I'm trying to
learn Unity where there they have the unity version control, so I now 
know that it helps save every change made to a project. If a mistake 
happens, it is possible to return to an earlier version instead of starting
over. GitHub also helps teams members work together on the same project
by keeping track of changes and making it easier to share updates. This
helps reduce mistakes and keeps everyone working on the latest version.

  Overall, the lesson helped me understand what cloud computing is and how
it is connected to many of the applications I already use every day. Even
though I am still new to this topic, I now have a better idea of how 
cloud services and version control are used.
